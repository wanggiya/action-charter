# Project Summary

GeoAgent Skill Harness is a CLI-first, local-first, containerized system for
planning approved GIS workflows, executing narrow tools, deterministically
validating outputs, and recording reproducible traces.

The first vertical slice will eventually inspect a vector dataset, load it into
PostGIS, validate the layer, generate a Markdown report, and save a JSON/JSONL
trace. Checkpoint 1 implements inspection only.
